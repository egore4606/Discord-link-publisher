# Support

## Questions and ideas

Use [GitHub Discussions](https://github.com/egore4606/Discord-link-publisher/discussions) for setup help, ordering questions, and feature ideas that are not yet concrete bug reports.

## Bug reports

Use the [bug report form](https://github.com/egore4606/Discord-link-publisher/issues/new/choose) when the behavior is reproducible. Include your operating system, Python version, command options, sanitized input, and terminal output.

Never publish a Discord webhook URL or private channel content. Replace them with placeholders before sharing logs or screenshots.

## Security issues

Do not report vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).
